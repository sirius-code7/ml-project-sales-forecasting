# ml-project-sales-forecasting

projet de machine learning consacré à la prévision du chiffre d'affaires / des ventes.

## objectif

construire un modèle de machine learning capable de prévoir les ventes à partir de données historiques.

## structure du projet

- `data/` : données utilisées pour le projet
- `notebooks/` : notebook principal du projet
- `src/` : éventuels scripts et fonctions réutilisables
- `.gitignore` : fichiers exclus du dépôt
- `README.md` : présentation du projet
